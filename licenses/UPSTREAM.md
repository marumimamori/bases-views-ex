# Upstream basis

This project is an expanded derivative of:

- **Project:** Obsidian Bases Spotlight View
- **Repository:** https://github.com/mymindstorm/obsidian-bases-spotlight-view
- **Original author / copyright holder:** Brendan Early / mymindstorm
- **Upstream manifest version inspected for this fork:** 1.1.4
- **License:** MIT

The expanded fork intentionally uses a new plugin ID and Bases view type so it can coexist with the original plugin.

The expanded implementation keeps the upstream concept and key behaviors (dual-pane preview/sidebar, Base-result navigation, image/PDF/Markdown preview, sidecar metadata, custom preview property, property ordering and resizing) while replacing the generic metadata text editing path with type-aware editors.
